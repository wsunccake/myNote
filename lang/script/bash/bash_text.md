# bash text

## sort

```csv
11,v11
1,v1
2,v2
10,v10
8,v8
```

```bash
linux:~ $ sort <csv_file>                   # 依第一欄, ascii 順序排列
linux:~ $ sort <csv_file>                   # 依第一欄, 數值 順序排列
linux:~ $ sort -k2 -V <csv_file>            # 依第二欄, 版本 順序排列
linux:~ $ sort -k2,2V -k1,1 <csv_file>      # 依第二欄, 版本 順序排列, 再依第一欄, ascii 順序排列
```

1. -k `n` (從第 `n` 欄開始到行尾)

只給一個數字，sort 會從第 `n` 欄開始，一直比對到該行的最後一個字元。

- 行為：如果第 `n` 欄一模一樣，它會自動往第 `n+1` 欄、第 `n+2` 欄繼續比下去。
- 例子：-k 2
  - 這代表排序參考：第 2 欄 + 第 3 欄 + ... 直到行末。

2. -k `n`,`n` (限定只看第 `n` 欄)

這是最精確的寫法，代表起始點是第 `n` 欄，結束點也是第 `n` 欄。

- 行為：僅參考第 `n` 欄。如果第 `n` 欄相同，它就不再往下比對（除非你後面還有接第二個 -k 條件）。
- 關鍵用途：配合 -u (Unique) 根據特定欄位去重時，一定要用這個寫法。
- 例子：-k 2,2
  - 這代表排序參考：只有第 2 欄。

3. -k `n`,`m` (跨欄位比對)

定義一個從第 `n` 欄到第 `m` 欄的區域作為排序依據。

- 行為：將第 `n` 到第 `m` 欄看作一個整體的字串來排序。
- 例子：-k 1,2
  - 這代表排序參考：第 1 欄 + 第 2 欄 的組合內容。

```csv
A 02 Z
A 01 B
```

| Command     | Key                  | Explain                                       |
| ----------- | -------------------- | --------------------------------------------- |
| sort -k 1   | `A 02 Z` 與 `A 01 B` | 全行比對，`A 01 B` 會排在前面。               |
| sort -k 1,1 | `A` 與 `A`           | 兩行被視為「相等」。若加 -u，第二行會被刪除。 |
| sort -k 1,2 | `A 02` 與 `A 01`     | 比對前兩欄，`A 01` 排在前面。                 |
