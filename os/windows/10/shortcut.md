# shortcut

## system 操作快捷鍵

| 快捷鍵             | 功能                       |
| ------------------ | -------------------------- |
| Win                | 打開「開始」選單           |
| Win + D            | 顯示桌面（最小化所有窗口） |
| Win + E            | 打開「檔案總管」           |
| Win + L            | 鎖定計算機                 |
| Win + Tab          | 打開任務視圖               |
| Alt + Tab          | 切換開啟的應用程序         |
| Ctrl + Shift + Esc | 打開「任務管理器」         |
| Win + R            | 打開「執行」窗口           |
| Win + S / Win + Q  | 打開搜尋                   |
| Win + I            | 打開「設定」               |
| Win + . / Win + ;  | 打開表情符號選擇器         |

---

## window 管理快捷鍵

| key              | function                      |
| ---------------- | ----------------------------- |
| Win + ↑          | maximize window               |
| Win + ↓          | minimize window               |
| Win + ←          | snap window to left           |
| Win + →          | snap window to right          |
| Win + M          | minimize all windows          |
| Win + Shift + ↑  |                               |
| Win + Shift + ↓  |                               |
| Win + Shift + ←  | move window to another screen |
| Win + Shift + →  | move window to another screen |
| Win + Shift + M  |                               |
| Win + Ctrl + D   | create virtual desktop        |
| Win + Ctrl + →/← | switch virtual desktop        |
| Win + Ctrl + F4  | close virtual desktop         |

---

## file 操作快捷鍵

| 快捷鍵         | 功能                           |
| -------------- | ------------------------------ |
| Ctrl + C       | 複製                           |
| Ctrl + X       | 剪切                           |
| Ctrl + V       | 粘貼                           |
| Ctrl + Z       | 撤銷                           |
| Ctrl + Y       | 重做                           |
| Ctrl + A       | 全選                           |
| F2             | 重命名所選文件或文件夾         |
| Shift + Delete | 永久刪除選定項目（跳過回收站） |

---

## text 編輯快捷鍵

| 快捷鍵                   | 功能                          |
| ------------------------ | ----------------------------- |
| Ctrl + 左/右箭頭         | 移動光標到上/下一個單詞的開頭 |
| Ctrl + 上/下箭頭         | 移動光標到上/下一段           |
| Ctrl + Shift + 左/右箭頭 | 選取上/下一個單詞             |
| Ctrl + Backspace         | 刪除光標前的一個單詞          |
| Ctrl + Delete            | 刪除光標後的一個單詞          |

---

## monitor & task 快捷鍵

| 快捷鍵          | 功能                       |
| --------------- | -------------------------- |
| Win + P         | 選擇投影模式（顯示器設置） |
| PrtScn          | 截取整個屏幕               |
| Alt + PrtScn    | 截取當前活動窗口           |
| Win + Shift + S | 打開截圖工具（選擇性截圖） |
