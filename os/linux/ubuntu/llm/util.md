## ui

1. [Open WebUI](https://openwebui.com/)

- 一個開源的 LLM 圖形化介面，支援本地和遠端 API 方式的模型交互（如 OpenAI、Ollama）。
- 提供簡單的 UI，適合非技術用戶與 LLM 互動。
- 可自訂 API 設定，方便連接不同的 LLM 服務。

2. [Langflow](https://www.langflow.org/)

- 以視覺化方式搭建 LLM 工作流的開源工具，類似於 Node-RED。
- 主要基於 LangChain，可快速組合不同 LLM 模組，如記憶、查詢、函數調用等。

3. [Flowise](https://flowiseai.com/)

- 基於 LangChain 的視覺化 LLM 構建工具。
- 提供 UI 讓開發者透過拖拉節點的方式搭建 LLM 應用。

4. [Dify](https://dify.ai/)

- 即用型 LLM 應用開發平臺，適合無程式碼或低程式碼開發者。
- 可以用來構建 AI 助理、聊天機器人等，並支援 API 介接。

5. [Coze](https://www.coze.com/)

- 針對 AI 聊天機器人的視覺化開發工具，提供 Web 端 UI 來設計與測試聊天機器人。
- 適用於客服、自動化助理等應用。

6. [Anything LLM](https://anythingllm.com/)

- 開源的 LLM 部署與應用管理工具，讓使用者可以本地運行自己的 LLM（如 GPT-4、LLaMA）。
- 提供 UI 介面來管理 LLM 啟動與使用情境。

7. [LlamaIndex](https://www.llamaindex.ai/)

- 專注於 LLM 檢索增強生成（RAG, Retrieval-Augmented Generation）的開源框架。
- 幫助 LLM 高效處理自有資料，如企業文件、數據庫、網頁等。

8. [LM Studio](https://lmstudio.ai/)

- 一款本地 LLM 部署與測試工具，適合用來運行 Ollama、LLaMA、Mistral、Gemma 等模型。
- 具備 GUI 介面，能輕鬆管理和測試 LLM。
