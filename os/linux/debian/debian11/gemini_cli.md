# gemini cli

## install

prerequisites: node.js 18+

```bash
debian:~ $ npm install -g @google/gemini-cli
```

---

## setting

Generate a key from [Google AI Studio](https://aistudio.google.com/apikey)

```bash
debian:~ $ export GEMINI_API_KEY="<API_KEY>"
debian:~ $ npm -g x gemini
```
