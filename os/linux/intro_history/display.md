# display

## history

1. X11 (X Window System)

   - 誕生： X11 於 1987 年由 MIT 發布，是一個 **網路透明（network-transparent）** 的顯示協定。
   - 概念： 採用客戶端-伺服器（client-server）架構。應用程式是客戶端（X Client），而管理顯示輸出和輸入裝置的程式是伺服器（X Server）。這個架構使得應用程式可以在一台電腦上運行，而其圖形介面則顯示在另一台遠端電腦上。
   - 特色： X11 僅提供最基本的繪圖工具，例如視窗、字體、滑鼠游標等。它不負責視窗的排列、外觀設計或整體使用者體驗，這些功能交由外部的 **視窗管理器（Window Manager）** 來處理。
   - 演進： X11 的設計初衷是在當時有限的硬體環境下，為 Unix 工作站提供跨平台、可遠端操作的圖形介面。它成功解決了這個問題，並成為 Unix-like 系統的標準。

2. XFree86

   - 誕生： XFree86 於 1992 年作為一個開源專案啟動。
   - 概念： X11 協定的一個具體實作（implementation），專門為當時的 Intel x86 個人電腦設計。
   - 特色： XFree86 的主要貢獻是將 X11 帶到了個人電腦上，支援了各種顯示卡、鍵盤和滑鼠。在 1990 年代，它是所有主流 Linux 發行版預設的 X Server，讓 Linux 從命令列系統轉變為可用的桌面作業系統。
   - 演進： 商業版本的 X11 昂貴且不支援個人電腦硬體，阻礙了其在開源系統上的普及。XFree86 應運而生，它以開源的方式填補了這個空白。然而，後來的授權爭議導致了社群的分裂。

3. X.Org

   - 誕生： X.Org 於 2004 年成立，是從 XFree86 分支出來的專案。
   - 概念： 繼承了 XFree86 的程式碼，並在一個更開放、更具協作性的基金會下繼續開發。
   - 特色： X.Org Server 成為了新的主流 X11 實作，它持續維護、修補舊有的臭蟲，並添加了對現代顯示卡驅動程式和 3D 加速的支援。儘管如此，它的底層架構依然是基於 X11。
   - 演進： XFree86 的內部分歧和新授權條款引發了不滿，開發者們決定另起爐灶，以確保專案的開放性和持續性。X.Org 成功團結了社群，並成為 Linux 桌面在 2000 年代的主力。

4. Wayland

   - 誕生： Wayland 專案於 2008 年啟動，旨在徹底取代 X11。
   - 概念： 不是 X11 的新版本，而是一個全新的顯示協定。Wayland 摒棄了客戶端-伺服器模型，而是將 **合成器（compositor）** 作為核心。合成器同時處理顯示伺服器、視窗管理和繪圖的功能。
   - 特色：
     - 效能： 簡化了繪圖流程，消除了畫面撕裂（tearing），並提供更流暢的動畫。
     - 安全性： 應用程式之間無法互相存取繪圖內容或輸入事件，大幅提升了安全性。
     - 現代化： 架構更簡潔，更適合現代高解析度顯示器和 3D 繪圖。
   - 演進： X.Org 基金會做了許多努力，但 X11 的先天設計缺陷已難以根治。老舊架構難以應對現代圖形技術（如高解析度、多點觸控、GPU 加速），並且其「網路透明」的特性在現代桌面環境中反而成了安全隱患。Wayland 的出現是為了解決 X11 的這些根本問題，為 Linux 桌面提供一個更高效、更安全的未來。

| 特性     | X11                            | XFree86 / X.Org         | Wayland                               |
| -------- | ------------------------------ | ----------------------- | ------------------------------------- |
| 角色     | 顯示協定                       | X11 協定的實作          | 全新的顯示協定                        |
| 架構     | 客戶端-伺服器                  | 客戶端-伺服器           | 合成器（Compositor）                  |
| 優點     | 網路透明、高度可擴展           | 使 X11 普及至 PC        | 效能高、安全性佳、架構簡潔            |
| 缺點     | 架構老舊、效能差、有安全性問題 | 繼承了 X11 的所有缺點   | 相容性仍有挑戰、生態系仍在建構        |
| 為何演進 | 奠定基礎                       | 將 X11 帶入開源 PC 生態 | 解決 X11 根本性問題，迎接現代顯示技術 |
