# input / 輸入法

## history

1. 歷史的起點：XIM 與 CXWin (1990 年代)

   在一切輸入法框架出現之前，XIM (X Input Method) 協議是 Linux 系統上處理多國語言輸入的基礎。它本身並非一個輸入法程式，而是一個標準化的通訊協定，允許應用程式與輸入法後端進行溝通。然而，XIM 僅提供了最基本的架構，實際的輸入法實作則需由不同的專案來完成。

- CXWin (Chinese X-Windows): 這是早期針對中文輸入的具體實踐之一。它是一個獨立的輸入法程式，通常與 chinput 等輸入法引擎配合使用。
  - 特色：CXWin 的設計非常簡單、輕量，專注於提供基本的中文輸入功能。它沒有複雜的框架或擴充性，主要為了解決當時 Linux 系統無法輸入中文的痛點。
  - 歷史定位：CXWin 代表了 Linux 中文輸入的早期摸索階段，是從無到有的先驅，為後來的發展奠定了基礎。

2. 框架的誕生：SCIM 與 Gcin (2000 年代初期)

   隨著 Linux 桌面環境的成熟，使用者需要一個更通用、更強大的輸入法框架來取代單一的解決方案。SCIM 和 Gcin 在此背景下應運而生，並成為各自社群的主流。

- SCIM (Smart Common Input Method):

  - 衍生歷史：SCIM 旨在建立一個通用、可擴充的多語言輸入框架，希望透過單一架構來支援所有語言。它在 2000 年代初期迅速普及，成為許多 Linux 發行版（如 Ubuntu、Fedora）的預設輸入法，取代了早期的 CXWin 和 chinput。
  - 特色：其模組化的設計是最大亮點，允許使用者輕鬆載入不同的輸入法引擎（如 SCIM-pinyin、SCIM-chewing）。然而，SCIM 龐大的架構和複雜性也導致了性能不佳、偶爾不穩定等問題。
  - 歷史定位：SCIM 是第一代成功的通用輸入法框架，為後來的 IBus 和 Fcitx 提供了重要的經驗。

- Gcin:

  - 衍生歷史：Gcin 與 SCIM 同期發展，但其起源和主要目標不同。它由台灣開發者專為繁體中文使用者設計，特別針對注音輸入法進行了深度優化。
  - 特色：Gcin 以其快速、穩定和豐富的內建功能而聞名。它提供了自訂詞庫、自動選字等功能，深受台灣 Linux 社群的歡迎。Gcin 的設計更注重效能，避免了 SCIM 的笨重。
  - 歷史定位：Gcin 是繁體中文輸入法歷史上的重要里程碑，證明了專注於特定語系的輸入法可以達到更佳的使用體驗。

- Hime:
  - 衍生歷史：Hime 是一個基於 Gcin 的分支專案。它的創建是為了解決 Gcin 在某些新環境（如 GTK+ 3 和 Wayland）上的相容性問題，同時保留其核心優勢。
  - 特色：Hime 繼承了 Gcin 的高效和穩定，並改進了與現代桌面環境的整合，使其在一些發行版中成為 Gcin 的替代方案。
  - 歷史定位：Hime 是 Gcin 在新時代的延續，顯示了專案如何透過分支來適應不斷變化的技術環境。

3. 新時代的崛起：IBus 與 Fcitx5 (2000 年代中期至今)

   到了 2000 年代中期，Linux 桌面日趨成熟，對輸入法提出了更高的要求，特別是關於穩定性、安全性與桌面整合。IBus 和 Fcitx5 應運而生，並最終成為當代 Linux 輸入法的兩大主流。

- IBus (Intelligent Input Bus):

  - 衍生歷史：IBus 於 2007 年左右誕生，旨在徹底取代 SCIM。它採用了 D-Bus 通訊協定，讓輸入法後端與前端分離，即使輸入法引擎崩潰，也不會導致整個系統凍結。
  - 特色：IBus 的核心優勢在於穩定性與安全性。它與 GNOME 桌面環境有著最深度的整合，提供了最流暢的開箱即用體驗。然而，其性能在某些情況下可能不如 Fcitx5。
  - 歷史定位：IBus 是第一個廣泛被接受的「新一代」輸入法框架，被許多主流發行版預設採用，確立了現代輸入法框架的標準。

- Fcitx5 (Flexible Input Method Framework):
  - 衍生歷史：Fcitx 早在 SCIM 時代就已存在，但當時影響力有限。隨著 IBus 流行，Fcitx 開發者決定從零開始，將整個框架用 C++ 重寫，創造了 Fcitx5。它旨在提供比 IBus 更佳的效能、更強的客製化能力。
  - 特色：Fcitx5 採用更現代的架構，與 KDE Plasma 桌面有著完美的整合。它在 Wayland 環境下的表現尤為出色。Fcitx5 提供了豐富的功能，例如內建的剪貼簿管理器、強大的主題引擎以及多樣化的輸入法引擎支援。
  - 歷史定位：Fcitx5 是當前 Linux 輸入法框架的集大成者，代表了高效能、高度客製化和對新技術的全面支援。
