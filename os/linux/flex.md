# lex / flex 詞法分析器生成工具

`lex` (或 `flex`) 工具在編譯器設計中扮演著關鍵角色，用於自動生成詞法分析器 (Lexical Analyzer)，也稱為掃描器 (Scanner)。詞法分析器負責將原始程式碼分解成一系列有意義的符號，稱為 Token。

## 了解詞法分析 (Lexical Analysis)

詞法分析是編譯器前端的第一個階段。它的主要任務是讀取原始程式碼的字元流，並將其分組為有意義的單元，即 Token。例如，在 `int x = 10;` 這行程式碼中，詞法分析器會識別出 `int` (關鍵字 Token)、`x` (識別字 Token)、`=` (運算符 Token)、`10` (整數常數 Token) 和 `;` (分隔符 Token)。

---

## `lex` 與 `flex` 簡介

- **`lex` (Lexical Analyzer Generator)**: 是一個 UNIX 工具，用於生成詞法分析器。它接受一個包含正則表達式和對應動作的規範文件，然後生成一個 C 語言原始碼文件，該文件可以被編譯以執行詞法分析。
- **`flex` (Fast Lexical Analyzer Generator)**: 是 `lex` 的一個更快速、更現代的替代品。`flex` 與 `lex` 高度相容，並提供了許多性能上的改進和額外功能。在現代開發中，`flex` 通常是首選。

### `flex` 規範文件結構

`flex` 的輸入文件（通常以 `.l` 結尾）分為三個主要部分，由 `%%` 分隔：

```flex
%{
// 定義區 (Definitions Section)
// 包含 C 語言的變數宣告、頭文件包含、巨集定義等。
// 這些內容會直接複製到生成的 C 檔案的開頭。
%}

// 選項區 (Options Section) (可選)
// 例如 %option noyywrap 禁用默認的 yywrap() 函數

%%

// 規則區 (Rules Section)
// 包含一系列正則表達式 (Pattern) 和對應的 C 語言動作 (Action)。
// 當詞法分析器匹配到某個 Pattern 時，就會執行其對應的 Action。
pattern1 { action1 }
pattern2 { action2 }
...

%%

// 使用者程式碼區 (User Code Section)
// 包含任何額外的 C 語言函數，例如 `main()` 函數、輔助函數等。
// 這些內容會直接複製到生成的 C 檔案的結尾。
int main() {
    // 通常會呼叫 yylex() 啟動詞法分析
    yylex();
    return 0;
}
```

### Definitions Section / 定義區

用於宣告 C 語言的變數、包含頭文件、定義巨集或正則表達式的別名。

**範例:**

```flex
%{
#include <stdio.h>
#include <stdlib.h> // 為了使用 exit()

// 宣告全域變數來計數不同類型的 Token
int num_count = 0;
int id_count = 0;
%}

// 定義正則表達式的別名，方便在規則區使用
DIGIT     [0-9]
LETTER    [a-zA-Z]
INTEGER   {DIGIT}+
IDENTIFIER {LETTER}({LETTER}|{DIGIT})*
```

### Rules Section / 規則區

`flex` 的核心，定義了如何識別 Token。每一行包含一個正則表達式 (Pattern) 和一個 C 語言程式碼塊 (Action)。當輸入流匹配到某個 Pattern 時，`flex` 會執行對應的 Action。

`yytext` 是一個指向匹配到的字串的指標，`yyleng` 則表示匹配到的字串長度。

**常用正則表達式模式:**

| Pattern                     | 匹配內容                                       | 說明                                       |
| :-------------------------- | :--------------------------------------------- | :----------------------------------------- |
| `[0-9]`                     | 0 到 9 之間的任意數字                          | 單一數字                                   |
| `[0-9]+`                    | 一個或多個 0 到 9 之間的數字                   | 整數 (e.g., `123`, `4`)                    |
| `[a-zA-Z]`                  | 任意大小寫英文字母                             | 單一字母                                   |
| `[a-zA-Z_][a-zA-Z0-9_]*`    | 以字母或底線開頭，後接零或多個字母、數字或底線 | 識別字 (e.g., `myVar`, `_count`, `func1`)  |
| `"[^"]*"`                   | 雙引號括起來的任意字元 (不含雙引號本身)        | 字串常數 (e.g., `"hello world"`)           |
| `\/\/.*`                    | 雙斜線開頭直到行尾                             | 單行註解                                   |
| `\/\*([^*]\|\*+[^*/])\*+\/` | 斜線星號開頭，星號斜線結尾                     | 多行註解                                   |
| `\n`                        | 換行符號                                       |                                            |
| `.`                         | 除換行符外的任意單一字元                       |                                            |
| `\*`                        | 零個或多個前一個元素                           | (e.g., `a*` 匹配 `""`, `a`, `aa`)          |
| `\+`                        | 一個或多個前一個元素                           | (e.g., `a+` 匹配 `a`, `aa`)                |
| `\?`                        | 零個或一個前一個元素                           | (e.g., `a?` 匹配 `""`, `a`)                |
| `\|`                        | 或 (OR)                                        | (e.g., `int` \| `float`匹配`int`或`float`) |
| `()`                        | 分組                                           |                                            |
| `{alias}`                   | 引用定義區中的正則表達式別名                   | (e.g., `{INTEGER}` 引用 `[0-9]+`)          |

**範例:**

```flex
%%
{INTEGER} {
    printf("找到整數: %s\n", yytext);
    num_count++;
}

{IDENTIFIER} {
    printf("找到識別字: %s\n", yytext);
    id_count++;
}

"if"        { printf("找到關鍵字: if\n"); }
"else"      { printf("找到關鍵字: else\n"); }
"+"         { printf("找到運算符: +\n"); }
"="         { printf("找到運算符: =\n"); }
";"         { printf("找到分隔符: ;\n"); }

[ \t]+      { /* 忽略空白和 Tab */ }
\n          { /* 忽略換行符 */ }
.           { printf("未知字符: %s\n", yytext); } // 匹配所有其他單一字符
%%
```

### User Code Section / 使用者程式碼區

此區域包含任何額外的 C 語言程式碼，例如 `main()` 函數，它會呼叫 `yylex()` 來啟動詞法分析過程。

**範例:**

```flex
%%
/* 規則區結束 */
%%

/* 使用者程式碼區 */
int main() {
    printf("--- 詞法分析開始 ---\n");
    // 呼叫詞法分析器開始處理輸入
    // yylex() 會從標準輸入 (stdin) 讀取，直到遇到檔案結束符 (EOF)
    yylex();
    printf("--- 詞法分析結束 ---\n");
    printf("總共找到整數: %d 個\n", num_count);
    printf("總共找到識別字: %d 個\n", id_count);
    return 0;
}

// yywrap() 函數在 flex 處理完一個輸入檔案後被呼叫。
// 默認情況下，它返回 1 表示沒有更多輸入。
// 如果需要處理多個輸入檔案，可以重寫此函數。
int yywrap() {
    return 1;
}
```

## `flex` 使用流程

1.  **編寫 `flex` 規範文件**: 創建一個 `.l` 檔案 (例如 `lexer.l`)，並在其中定義詞法規則。
2.  **使用 `flex` 生成 C 程式碼**:
    ```bash
    flex lexer.l
    ```
    這會生成一個名為 `lex.yy.c` 的 C 語言原始碼文件。
3.  **編譯生成的 C 程式碼**:
    ```bash
    gcc lex.yy.c -o lexer -lfl
    ```
    `-lfl` 選項用於連結 `flex` 庫，該庫包含了 `yylex()` 和 `yywrap()` 等函數的實現。
4.  **執行詞法分析器**:
    ```bash
    ./lexer < input.txt
    ```
    或者直接從標準輸入讀取：
    ```bash
    ./lexer
    // 然後手動輸入內容，按 Ctrl+D 結束輸入
    ```

## 內建變數與函數清單

核心函數 (Function)

| function      | type     | 說明                                                                                                                                                  |
| ------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| yylex()       | int      | 詞法分析器的主入口。 呼叫此函數開始詞法分析。它會讀取輸入，匹配規則，執行 Action，並通常在找到一個 Token 時回傳一個值（例如 Token 類型編號）。        |
| yywrap()      | int      | 在輸入結束時被呼叫。如果回傳 `1`，表示輸入結束；如果回傳 `0`，表示還有更多輸入來源需要處理 (例如讀取下一個檔案)。Flex 預設會提供一個回傳 `1` 的版本。 |
| yymore()      | function | 讓下一個 Token 匹配結果附加到當前的 `yytext` 之後。這用於處理需要多個匹配階段的 Token。                                                               |
| yyless(n)     | function | 將 `yytext` 的最後 n 個字元放回輸入流中，讓它們成為下一個 Token 匹配的開始。                                                                          |
| yyterminate() | function | 停止詞法分析器並立即回傳。 (通常在 Flex 中用於更精確的控制，而不是直接呼叫 exit())                                                                    |

核心變數 (Variables)

| variable | type    | 說明                                                                                                                               |
| -------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| yytext   | char \* | 指向當前匹配到的 Token 字串（即正則表達式匹配到的內容）。在 Action 中，這是您操作 Token 內容的主要變數。                           |
| yyleng   | int     | 當前匹配到的 Token 的字元長度。                                                                                                    |
| yyin     | FILE \* | 詞法分析器的輸入檔案指標。預設指向 stdin。您可以通过賦值給它來指定讀取特定的檔案。                                                 |
| yyout    | FILE \* | 詞法分析器的輸出檔案指標。預設指向 stdout。ECHO 宏會將內容寫入此處。                                                               |
| yylineno | int     | 當前行號。如果使用 %option yylineno 選項，Flex 會自動維護這個變數。如果沒有，則需要您在規則中自行維護 (通常是在匹配到 \n 時增加)。 |

核心宏 (Macro)

| macro        | 說明                                                                                    |
| ------------ | --------------------------------------------------------------------------------------- |
| ECHO         | "等同於 fprintf(yyout, ""%s"", yytext);。它會將當前匹配到的 Token 內容原封不動地輸出。" |
| BEGIN(state) | 用來切換詞法分析器的啟動狀態 (Start Condition)。例如：BEGIN(COMMENT);。                 |

option variables

| variable | type    | 說明                                                                                                                                                                          |
| -------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| yylval   | YYSTYPE | Token 的語義值 (Value)。當 yylex() 被呼叫並返回一個 Token 類型時，yylval 用來存放該 Token 實際代表的值 (例如數字的值、識別字的名稱字串)。需要配合 %option bison-bridge 使用。 |
| yylloc   | YYLTYPE | Token 的位置資訊 (Location)。用來記錄 Token 在輸入檔案中的起始和結束行/列號，以提供更好的錯誤報告。需要配合 %option bison-locations 使用。                                    |

## `lex` 與 `flex` 的異同

| 特性         | `lex`                              | `flex`                                                                                      |
| :----------- | :--------------------------------- | :------------------------------------------------------------------------------------------ |
| **全稱**     | Lexical Analyzer Generator         | Fast Lexical Analyzer Generator                                                             |
| **起源**     | UNIX 系統的標準工具                | `lex` 的 GNU 實現和改進版本                                                                 |
| **性能**     | 相對較慢                           | 通常比 `lex` 更快，效率更高                                                                 |
| **功能**     | 提供基本的詞法分析器生成功能       | 提供了 `lex` 的所有功能，並增加了一些擴展和改進，例如更強大的正則表達式支持、條件開始狀態等 |
| **相容性**   | 較舊的系統可能仍使用 `lex`         | 與 `lex` 高度相容，大多數 `lex` 文件可以直接用 `flex` 處理                                  |
| **維護**     | 較少維護                           | 積極維護和開發中                                                                            |
| **現代應用** | 較少直接使用，多用於歷史或特定環境 | 現代編譯器和語言工具開發的首選                                                              |
