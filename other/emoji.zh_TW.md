# Emoji

在撰寫 `README.md`、`Git Commit` 訊息或是專案文件時，加入 `Emoji` 可以大幅提升文件的視覺可讀性與美觀度。

---

## 🔍 去哪裡查？（Emoji 工具網站）

想找更多圖示，可以直接到以下這幾個最常用的 Emoji 數據庫網站搜尋（直接複製貼上即可）：

- [Gitmoji](https://gitmoji.dev/)（強烈推薦）：這是一個專門為開發者設計的網站，定義了在不同的開發階段（如：修 Bug、新增功能、優化效能）該用什麼 Emoji。
- [Emojipedia](https://emojipedia.org/)：最權威的 Emoji 百科全書，可以查到所有 Emoji 在不同系統（Apple, Google, Windows）上的長相。
- [Copy and Paste Emoji](https://getemoji.com/)：最簡單的複製貼上網站，分類清晰。

## 🛠️ 技術文件常用 Emoji 推薦

在編寫 README 或自動化腳本說明時，以下是技術社群約定俗成的常用圖示分類：

1. 執行與啟動（Action & Execution）
   - 🚀 :rocket:：啟動、發布、部署（例如：🚀 啟動模擬器）
   - ⚡ :zap:：效能優化、快速執行
   - 🔄 :arrows_counterclockwise:：重啟、循環、Loop 監控
   - 🛑 :stop_sign: 或 ⏹️：停止、關閉服務

2. 設定與配置（Configuration & Structure）
   - 📋 :clipboard:：前置準備、需求列表、指令清單
   - ⚙️ :gear:：系統設定、環境變數配置（例如：⚙️ 參數設定）
   - 📂 :file_folder: 或 📄：檔案路徑、目錄結構說明
   - 🔧 :wrench:：工具安裝、腳本修復

3. 測試與監控（Testing & Monitoring）
   - 🔍 :mag:：查閱、日誌排查、檢視 Log（例如：🔍 Show tool version）
   - 📊 :bar_chart:：監控數據、dumpTool 統計
   - 🧪 :test_tube:：自動化測試、Robot Framework 整合
   - 🚨 :alarm_clock: 或 ⚠️：警告、注意事項、潛在錯誤

4. 文件說明（Documentation Features）
   - 💡 :bulb:：提示、小技巧、額外補充說明
   - 📌 :pushpin:：重要固定事項、必看重點
   - 📖 :book:：使用手冊、參考文件

## 💡 快捷鍵小技巧

在編寫文件時懶得開網頁複製，可以直接用電腦內建的快捷鍵呼叫 Emoji 面板：

- `Windows` 鍵盤：按下 `Win` + `.` (句點) 或 `Win` + `;` (分號)
- `Mac` 鍵盤：按下 `Command` + `Control` + `Space` (空白鍵)
